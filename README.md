# CS-300: Data Structures and Algorithms

This repository contains work from my CS 300 Data Structures and Algorithms course. The projects in this course focused on using different data structures and algorithms to organize, search, sort, and retrieve course information for an academic advising program.

## Reflection

### What was the problem you were solving in the projects for this course?

The main problem I was solving was how to organize and access course information for academic advisors at ABCU. The program needed to load course information from a file, store the information using an appropriate data structure, sort the courses in alphanumeric order, and allow a user to search for an individual course and view its prerequisites. In Project One, I compared different data structures to determine which one would work best for the program. In Project Two, I used what I learned to develop the working C++ application.

### How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by breaking it into smaller parts, such as loading the course data, storing it, sorting it, searching for courses, and displaying the results. I also considered the advantages and disadvantages of vectors, hash tables, and binary search trees. This helped me understand that choosing a data structure can affect the speed, memory usage, and overall efficiency of a program. Understanding data structures is important because different problems may require different ways of organizing and accessing information.

### How did you overcome any roadblocks you encountered while going through the activities or project?

One of the biggest things I learned was the importance of testing the program one part at a time. When I encountered problems, I went back through the code, checked the program logic, and tested different inputs to determine what was causing the issue. For example, I tested loading the course file, printing the complete course list, searching for courses with and without prerequisites, entering an invalid course, and entering invalid menu input. Working through these problems helped me become more comfortable debugging C++ programs instead of expecting everything to work correctly the first time.

### How has your work on this project expanded your approach to designing software and developing programs?

This project helped me understand that designing a program should happen before writing all of the code. Comparing data structures and developing pseudocode gave me a clearer idea of how the final program should work. I now think more about how information will be stored, how users will interact with the program, and how efficiently the program can retrieve and process information. It showed me how planning can make the coding process easier and more organized.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

My work in this course has helped me pay more attention to organization and readability when writing code. I learned the importance of using meaningful variable and function names, comments, separate functions for different tasks, and consistent formatting. Breaking a program into smaller functions also makes it easier to test, debug, and modify later. Going forward, I will continue focusing on writing code that another programmer can understand and maintain instead of only focusing on making the program work.
